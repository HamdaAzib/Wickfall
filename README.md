# WICKFALL

2D top-down action-RPG made in Unity 6. You play as a small candle golem
exploring a dark world. Your wax is both your health and your light: the
less wax you have, the smaller and dimmer your light becomes.

## Features
- Main menu (Play, Settings, Quit) with volume slider and controls list
- 4-direction movement with animations
- Wax (health) system, with a light that shrinks as wax is lost
- Phantom enemies that chase the player and clone themselves
- Wax pickups and braziers (checkpoints that refill your wax)
- HUD: wax bar and progress counter

## Controls
| Action | Key |
|---|---|
| Move | W A S D / Arrow keys |
| Attack | Space / Left click |

## Technologies
Unity 6, C#, URP 2D Lights, Animator, UI (TextMeshPro)

## How to run
Download the build from the **Releases** page, unzip it and run `Wickfall.exe`.
